# Home Lab Core

基于 Go 语言编写的 Linux 管理 Web 面板。

本项目提供一个 Web 图形界面（GUI）来管理 Linux 系统，目标是让用户通过可视化操作完成管理任务，而不是依赖控制台 / Shell 命令行。同时，项目以 **Lua 作为插件体系**，使外部组件能够轻松地被制作、接入并作为功能扩展。

## 设计理念

- **GUI 而非 Shell**：把常用的 Linux 管理操作封装成 Web 界面上的可视化操作，降低命令行使用门槛。
- **插件即功能**：以 Lua 作为插件语言，外部组件通过插件的形式接入，从而快速扩展面板能力，而不必改动核心代码。
- **轻量与可嵌入**：后端使用 Go 编写，便于部署在 Linux 主机、家庭实验室（Home Lab）或边缘设备上。

## 核心特性

- 基于 Go 的 Web 后端服务
- 面向 Linux 系统管理的 Web GUI
- 以 Lua 编写的插件体系，支持接入外部组件作为功能
- 插件化的功能扩展方式，减少对核心代码的修改

## 架构概览

```
┌─────────────────────────────────────┐
│             Web GUI (浏览器)         │
├─────────────────────────────────────┤
│          Go 后端服务 (HTTP)          │
├─────────────────────────────────────┤
│        Lua 插件运行时 / 插件系统      │
├─────────────────────────────────────┤
│   外部组件 / Linux 系统管理接口       │
└─────────────────────────────────────┘
```

- **Web GUI**：用户通过浏览器进行操作和管理。
- **Go 后端**：提供 HTTP 服务，处理 GUI 请求并调度底层能力。
- **Lua 插件体系**：承载插件逻辑，是外部组件接入系统的桥梁。
- **外部组件 / Linux 系统接口**：被管理与被集成的对象。

## 插件体系

插件体系是本项目的核心目标之一：

- 使用 **Lua** 编写插件，语法简单、易于上手。
- 外部组件可以作为插件接入，作为面板的一项功能对外提供。
- 通过插件方式扩展功能，避免把外部组件逻辑硬编码进核心程序。

插件的目录结构、加载方式、可用 API 与生命周期等规范将在后续文档中补充。
